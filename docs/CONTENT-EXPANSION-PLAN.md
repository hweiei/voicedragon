> 2026-09-19 · 用户选择「深耕现有三幕 + 变异词缀」；不新增第四幕。状态：实现完成，验收结果见文末。

技能复用九种现有机制，围绕多段增势、护甲换手、净化续航形成不同费用/功效取舍；不是新战斗系统。
事件新增地点、人物、粤语短句与至少两项明确收益/风险选择；奖励使用现有可靠动作。

## 架构与兼容

1. `content/expansion.ts`：增量技能、事件、道具，不改 P0–P5 基础表。注册表提供版本化池，lookup 与图鉴覆盖新旧全集。
2. 存档新增可选 `ruleset: "p7"`。缺失即 legacy，不升级进行中局。UI 新战役默认 P7；经典塔保留基础规则；API 默认 legacy 保持回放。
3. 引擎 startCampaign / startEndless 增加可选版本参数，新建 startDaily 入口（日期标识写入状态，刷新不丢每日身份）；版本贯穿跨幕与 load。
4. 所有奖励/商店/事件/宝箱从同一版本化池取值。道具 lookup 使用全集、掉落使用当前版本池，避免渲染与引擎脱节。
5. `core/mutators.ts`：纯函数表与独立种子派生，不使用主局 rngState。每日固定一组、无尽每五层换组；旧局无词缀。
6. 每日挑战禁用自适应系数，避免同日同种子因个人战绩不同而改变敌人数值；本地日期口径沿用既有实现，不宣称跨时区全服一致。
7. 两个词缀在爬塔与战斗界面常驻显示名字及准确规则；只影响可见战斗数值，不篡改原始语音识别分数。负向声韵修正写入现有 voiceBoost 通道。

## 词缀规则（初版）

压力：铁衣（敌初始护甲 +6）、猛攻（攻击 ×1.12 / 生命 ×0.9）、巨躯（生命 ×1.18 / 攻击 ×0.95）、噪潮（首句判定 -6）、逆风（首回合声气 -1 / 我方初始护甲 +8）、层甲（敌每次行动后护甲 +2）。
助力：护身（初始护甲 +8）、抢拍（首回合声气 +1）、清音（首句判定 +10）、破阵（敌开场破绽 2 回合）、回春（战斗开始回复 4）、昂扬（战斗声势 +1）。
组合值必须有边界：生命/攻击至少 1，声气非负，词缀去重；数据中不存函数，存档可 JSON 往返。

## 实施顺序与质量门

- A：内容增量及注册表 → 引擎版本接线 → 新技能/事件/道具契约。
- B：词缀纯函数 → 日常/无尽入口 → UI 常驻说明与存档恢复。
- C：P7 三幕各 300 局参考 Bot（均值 74），目标胜率 45–65%，零超时；旧版本仿真门不变。
- D：新增浏览器用例（P7 新局、词缀展示、刷新兼容），全量 `npm run ci` + Playwright + codegraph sync。

既有测试文件不改；新增测试覆盖实际 P7 执行路径，而非只检查数据长度。新增数值不靠放宽既有断言过门。
无新增运行时依赖/素材/网络请求。保持首包 350 KB gzip 红线。词缀采用静态文字，无额外晕动风险。

## 验收与限制

- 新内容可经正常奖励/事件/商店路径获得，在练习场与图鉴中可查。
- 扩展版本同种子同命令流确定；词缀采样不消费游戏 RNG；旧存档缺字段按基础版处理。
- 新技能描述与实际效果一致；粤拼音节数匹配短句字符数、声调可解析。自动检查不能代替母语者审校。
- 仿真是参考 Bot 的回归门，不等同于真人平衡保证；新增词缀组合另跑确定性与有限时长烟测，不宣称全部组合达到同一胜率。

## 实施结果

- 技能 **22 → 36**（每幕新增 4 / 5 / 5）；本幕新增总数分别 16 / 10 / 10，累计可抽池 16 / 26 / 36。
- 事件 **13 → 26**（10 / 8 / 8）；道具 **3 → 8**；词缀 **0 → 12**（36 种一利一弊组合）。
- 新技能示例：再嚟一次（1 气两段）、有力使力（增势）、稳住先（净化）、换个角度（护甲换手）、有攻有守（2 气攻守）。传统字形作为对应新招式识别备选；没有改动原评分算法。
- 新事件覆盖粥档晨光、裁缝铺灯、戏棚试声、转角问路、檐下避雨、潮汐钟房、码头面摊、遗落船票、夜航货仓、云阶歇脚、回音问心、断线纸鸢、最后一盏灯。
- P7 问义事件在作答前隐藏释义，并统一两项风险提示，避免界面直接泄露答案；作答后显示解释。
- 新道具为战术用途：竹编护身符 / 淡盐润喉水 / 姜汁提气饮 / 醒神折扇 / 破阵响板。拒绝使用时不消费；满气不浪费补气饮。
- 每日挑战日期/种子持久化，刷新后结算仍记账；新旧规则分别写入日榜键，避免直接比较不同规则。战役解锁及历史星辉仍共用原元进度，不抹掉老玩家成就。
- `main.ts` 战役包装器补齐版本参数转发；新增 E2E 确认新战役实际以 p7 写入存档。
