# P20-F1 分支教学塔

## 本批交付
不再只有随机场景名称：每次领取奖励后，下一层出现两个可选择的房间。

- **教学巷**：展示完整粤语、粤拼与提示；基础场景题；下一次奖励从至多 3 件未拥有锦囊中选 1。
- **实战街**：先展示普通话意图，隐藏粤语答案与释义；可听示范、求助展开提示；换用另一种情境题；下一次奖励开放全部未拥有锦囊。
- 第一层固定教学，之后每层可选；第六层为收束挑战，完成后结算不再掉落奖励。
- 同层两条路径练同一句话，不跳过前置课程、不以随机为由考未学的复杂句型；实战街仍可展开示范，零惩罚。
- 场景版本/选项顺序/教学巷奖励由种子决定；选择本身持久化。地图与结算展示路径。
- 属于可重玩的轻量分支结构，不声称已实现新版完整战斗构筑或多轮自由对话；原版冒险入口仍保留。

## 锦囊各有作用，不再重复领取
1. 慢声耳机：慢速示范降至 .55 倍。
2. 粤拼灯牌：实战街隐藏答案时保留粤拼辅助（每日回忆仍默认隐藏）。
3. 分句书签：分段示范按钮；长句按“我要 / 一杯 / 冻奶茶”等分段。
4. 情境罗盘：额外展示语用线索。
5. 随身词卡：可展开本局已完成表达与粤拼。

新局五次奖励不会重复。同一件辅助能越早拿到越早使用；后期剩余少于三件时按实际剩余展示。
旧版纪念章仍可读档，但不进入新奖励池。旧存档已有重复物品不删除、不篡改历史。

## 实现与兼容
- `branches.ts`：路线类型、场景变体、分句/语用线索、种子奖励选择，全部纯规则。
- `branch-view.ts`：分岔卡、奖励卡、道具学习辅助 UI，与主页面分离。
- `Progress.routes`：当前楼层尚未选路时长度等于 floor，选定后等于 floor+1；第一层永远 coach；校验不允许跳层。
- 旧档无 routes 字段按已到达楼层填 coach，保留当前进度；此后进入新分支选择。
- 录音/阅读仍分开统计，没有增加分数或发音准确度判断。
- 学习手账复习使用原基础内容，不因本局路线变更而打乱复习队列。
