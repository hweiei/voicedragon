## 为什么这张表重要

游戏收入 = UV × 广告展示率 × eCPM。三处广告位（extraCard/revive/插屏）代码已就位但 **AD_UNITS 留空不展示**——流量主开通（门槛 UV≥500，以官方最新规则为准）是收入路径的第一道闸。

## 红线（做了会被限流或驳回复审）

- ❌ 买量刷量、激励安装（污染流量主审核，得不偿失）
- ❌ 任何「分享得奖励」话术（与游戏内合规设计保持一致：分享无奖励）
- ❌ 借 Duolingo/杀戮尖塔名义宣传（差异化定位文案：「不是背单词，是学会接话」）

## 时序

```
提审发布 → [自然流+视频号+社区帖] → 2-4 周达 500 UV → 申请流量主(1-3 工作日)
→ 后台建 3 个广告位拿 adUnitId → 填 minigame/src/config.ts → 走一遍 npm run gate → 再提审
→ 审核通过即开始产生收入（激励视频 eCPM 通常显著高于插屏/banner，优先保证前两者曝光场景不改）
```
