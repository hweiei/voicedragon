## 一、游戏基本情况

《声震龙楼》（微信小程序 AppID：wx66ad516be4157de5）是一款粤语口语学习类休闲小游戏，以「街坊卡牌闯关」为核心玩法：玩家听一句粤语生活用语，从手牌中选择正确的应答，并可按住录音跟读、获得发音评分。内容覆盖茶餐厅、出行问路、邻里往来、职场、就医、节庆六个生活场景，共 110 句常用语、24 位 NPC、18 个事件、12 个语法知识点。游戏无账号系统、无服务器、无内购、无虚拟支付。

## 三、玩法与功能说明

1. 核心循环：听示范音 → 选手牌应答 → 录音跟读 → 发音评分影响伤害 → 章节推进。
2. 学习系统：间隔重复温习、生词地摊、词块拼句课，均为单机算法。
3. 数据：无任何网络请求（仅微信 SDK 自身必要通信）；`networkTimeout` 配置为 10s，预留未来内容更新，当前版本无自定义服务器。
