# 微信小游戏合规与上线备忘（个人主体 / IAA）

> status: active · updated: 2026-09-30 · 政策以微信官方文档为准，本文件只记结论与出处。

## 路线结论（个人开发者、无版号、目标广告收入）

- 个人主体走 **IAA（流量主广告）**，不需要版号；不能开内购（虚拟支付对个人关闭）。
- 流程顺序：微信认证（300/年）→ 小游戏备案（平台初审 1–2 工作日 + 主管部门 10–20 工作日，
  驳回重排队）→ 版本具备**适龄提示** → 发布需小程序备案号下号。
- 备案三件套模板：自查自审报告、著作权声明、平台代办授权书；软著非必需但显著降驳回率。
- 类目：一级固定「游戏」不可改；二级发布前可改，选 **休闲游戏**；个人主体选不了文化互动/角色/牌类。
  名称需与玩法相关且唯一。
- 适龄提示建议 **12+**（教育向对话玩法；避开「幼儿不宜复杂操作」驳回点）。
- 隐私声明只报「麦克风」：录音仅设备端实时评分，不上传不保存（如实——架构上零后端）。
- 流量主开通门槛：累计独立访客 > 500。

## 广告实现的红线（代码里已按此设计）

- 无 banner；激励视频仅两处（每场一次补牌 / 每局一次复活）；插屏有频控（前 2 局不弹、间隔 ≥3 分钟）。
- **不做分享奖励**（诱导分享封禁面）；只开放普通转发菜单。
- 广告位 id 留空 = 全链路静默跳过（可安全提交无广告版）。
