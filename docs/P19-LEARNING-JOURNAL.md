# P19-F1 学习手账与每日回忆

## 为什么做
P18 的六层教学塔只有单局记录。重开后没有长期练习跟进，也不能区分接触、阅读、录音与真正掌握。本批增加独立学习手账，不把游戏通关或自评包装为客观掌握度。

## 已实现
- 手账独立键 `voice-dragon-beginner-journal-v1`，单局重置不清空。
- 每句聚合：阅读次数、录音尝试次数、复习次数、最近时间、下次到期、自评与间隔。没有音频、识别文本或发音评分。
- 回忆队列仅从已练句子选取，优先到期，默认最多三句。没有到期内容也可以主动回顾。
- 复习先隐藏粤语答案/粤拼/释义；未录音、未选阅读模式、未展开提示前不展示场景选择，避免答案提前泄露。
- 正常完成场景题并录音/明确选择阅读后，才可自评。
- “还要练”：10 分钟后；“记起来了”：间隔 1/2/4/8/14 天（普通新学首次 1 天，后续成功自评从 2 天开始）。该调度是简化自评规则，不是经过学习效果验证的模型。
- 一般重玩不推迟已经到期的复习任务；只有复习自评改变间隔。
- 复习不改变爬塔楼层、奖励或原版冒险档案。可退出，已完成的单句保留，未完成复习会话不存档。
- 单局引入独立 UUID；当前旧存档按 legacy-seed 稳定迁移，一句最多补记当前局已确认的一次，不推测更早历史。
- 有界 recentEvents 防止刷新重复统计；最近 1000 个事件去重。存档严格白名单与范围校验。
- 存储不可写时显示提示，允许本页临时练习。清除网站数据仍会丢失记录，当前没有跨设备同步或手账导入导出。

## 模块
- `journal.ts`：纯规则、调度、白名单恢复、回忆提示。
- `journal-view.ts`：手账渲染。
- `progress.ts`：兼容旧单局的 runId。
- `app.ts`：复用已有示范、录音和场景题能力，不另造语音接口。

## 产品上仍缺什么（下一批顺序）
1. **有学习意义的分岔路线**：教学前置保持固定，选择训练方式（强提示/情境迁移/复习）而非只换场景名；奖励避免重复同一道具无收益。
2. **可靠的粤语示范**：固定音频、正常/慢速、逐句审校与来源版本；浏览器 TTS 只作有能力时的补充。
3. **情境内容深化**：先扩展茶餐厅的替换表达和多轮问答，再扩场景；不靠题库数字堆量。
4. **真实用户/设备试用**：普通话母语零基础用户、手机录音、Safari、无粤语音色设备与离线场景；自动化不能替代口音和学习效果验证。
5. **发布**：目前仅评审分支，Git SSH 部署密钥可推送，不代表有 GitHub API 权限。需要创建/审阅 PR，再明确决定合并 main 与部署；本批未合并、未自动部署。

## 不做的误导
- 录音文件存在 ≠ 有效开口；ASR 文本命中 ≠ 发音合格；自评记起来了 ≠ 已掌握。
- 新手手账未写入原版基于评分的 SRS，避免把阅读或自评伪装成发音分数。
