# P8-B · 对手进化详细方案

> 2026-09-19 · 用户选择进入 P8-B；先制定本方案，再实施。状态：**实现与本地验收完成**（先方案后实现）。
> 不增加第四幕、新语音惩罚系统或特效；不修改既有测试来放宽验收。

## 1. 目标

让现有构筑需要根据对手调整出牌顺序，而不是只比较伤害数值。
交付范围：**三个现有 Boss 各增加一个第二阶段、每幕新增一个特色精英（共三名）、准确的意图预测及应对说明**。
保留原三幕基础数据、经典塔、每日、无尽、P7/P8-A 进行中存档。

## 2. 核心公平规则：不偷换已经显示的意图

- 每个 Boss 从开战就显示「生命降至 50% 或以下会准备第二阶段」及第二阶段风格。
- 玩家一次技能完整结算后检查阈值；如果 Boss 仍活着，标记 `pending`，不立即换意图、不反击、不回血。
- 本次敌方回合先按原本显示的意图行动。若玩家存活，在行动结束后切入第二阶段。
- 第二阶段第一招统一为 **蓄势**：无直接伤害，行动后露出破绽一轮；再轮到玩家时可以利用此窗口。
- 阈值跨越不会打断多段伤害；一击击杀直接胜利，不强制锁血或复活。
- 阶段只前进一次，阶段内使用独立起始回合索引；刷新存档不重放切换、不重置意图。
- 下一句发音干扰沿用既有 score 修正，对语音/QTE 一致；不修改 ASR 原始结果。

括号中的攻击倍率基于当前敌人基础攻击，随战役曲线与敌方虚弱调整；固定吞音不乘基础攻击。
上述行动数值保留先行方案；通过 P8-B 独立战役曲线校准整体胜率（见 §10）。不得以隐藏伤害、回血复活、强制语音输入增加难度。
「露隙」= 敌方行动结束后易伤 1 轮，下一轮玩家攻击伤害 +25%，随后敌方行动结束时消退。

## 5. 意图预测必须与实际结算共用公式

新增 `core/encounters.ts` / `core/content/encounters.ts`：
- 纯规则表保存 Boss 第二阶段与新精英；不在数据中存函数。
- `resolveEnemyAction` 将 intent + 基础攻击 + 虚弱变为每段伤害、段数、穿甲、护甲、声韵干扰、露隙。
- `resolveIncomingHit` 是护甲/玩家易伤/龙鳞音甲/穿甲的单段结算纯函数。预测与真实受击共用，不维护两套近似公式。
- `forecastEnemyAction` 按每一段依次计算，不能简单用「总伤害减一次护甲」；显示当前状态下预计生命损失（最多当前HP）与护甲抵消量。
- 新版意图卡展示：逐段伤害、段数、穿甲标识、敌方加甲、下一句分数修正、露隙及条件性预测。用文字与数字，不只靠颜色。
- 预测注明「按当前状态」，玩家加甲/虚弱后重新渲染；不承诺尚未执行技能后的结果。
- 穿甲跳过护甲抵挡，也不触发龙鳞音甲补甲；不凭空清空玩家护甲，回合末仍按原规则清零。

新字段：`EnemyIntent.type` 增加 `charge`，可选 `pierce`、`selfVulnerable`；只在新内容中使用。
旧版 endTurn 与旧意图文案保留入口；公共受击纯函数的默认路径必须与旧行为等价。

## 11. 玩家路径与维护入口

1. 标题选择「战役 · 第一幕」（已解锁的幕也可直接新开）；标题与战役页显示新版本提示。
2. 每幕精英池保留原两名、加入该幕新精英；只抽一次RNG。
3. Boss 开战即显示半血条件；跨过阈值后看「变招准备」，本回合先执行已显示的招式。
4. 下一回合进入第二阶段，先蓄势；蓄势行动完成后看到「露隙1轮」，再利用该轮输出。
5. 加甲、虚弱、玩家易伤变化后，意图预测立即重算；穿甲明确提示“不靠堆甲抵挡”。
6. 继续旧存档仍用旧玩法；要体验新对手，需要开一局新战役。跨幕续行会保留新版本。
