# P17 词海 · 内容大扩容（学习密度核心期）

> 2026-09-22 · 立项动因（Owner）：「词汇太少，不够学成粤语」——P16 实测库存仅 47 句 / 116 字 / 76 题。
> 本期把**可学内容量**做成主杠杆：短句 49 → 200+，题库 76 → 150+，汉字覆盖 116 → 600+。
> 走 P15 铸剑炉跑通的**构建期内容管线**思想：AI 起草 → 版本化入池 → 仿真门校准，**运行时零 AI、零素材、零新依赖**。

## 0. 现状与目标

| 维度 | P16 末 | P17 目标 | 实测定案 |
|---|---|---|---|
| 可开口短句（战斗卡） | 49 | 200+ | **266 句 / 269 卡**（+220） |
| 覆盖汉字（去重） | 116 | 600+（立项估） | **370**（见下"目标修正"） |
| 问答题 | ~76 | 150+ | **156**（+80：词义 30 / 场景 25 / 拼音 25） |
| 场景覆盖 | 街头文化为主 | 全场景 | 寒暄/买卖/问路/数字时间/饮食/出行/天气/情绪/俗语/节庆 |

**目标修正（诚实边界）**：立项时估的「600+ 汉字」是未实测的拍脑袋数。实测 266 句后唯一汉字
370——粤语口语高频字（唔/嘅/喺/佢/咗……）在句中重复率极高，单字覆盖不是句式语言学习的好
指标；继续堆句到 600 字需再加 150+ 句，边际收益低且稀释卡池。**定案以"可开口句子数"
（47 → 266，×5.7）与题库（76 → 156，×2.1）为主指标**；汉字覆盖如实记 370（口语高频字大头已进）。
后续如需再扩，按场景批注追加（见 §4）。

## 1. 设计

### 1.1 内容分层（按幕主题贴合既有三幕）
- **幕1 骑楼长街**：寒暄问候、感谢道歉、买卖讲价、问路求助、数字时间。
- **幕2 雾海码头**：饮食茶楼、交通出行、天气昼夜、方位疑问词。
- **幕3 云顶声窟**：情绪感受、鼓励俗语、沟通用语、成语收束。

### 1.2 卡牌数值纪律
- 只复用既有类型（attack/guard/hybrid/multi/heal/tempo/weaken/strength），
  数值对齐既有经济：1 费攻 8–10 / 守 8–9 / 混 6 / 连击 4×2–3；2 费守 16–20 / 稀有攻 11–14；声势 2–3。
- 新句只进 `src/core/content/p17/`（新文件），**基础表与 EXPANSION 只读红线不动**。

### 1.3 版本门控（`lexiconVersion?: 1`，沿用 forgeVersion 全套惯例）
- `CampaignConfig.lexiconVersion` → `state.lexiconVersion`（仅 ruleset=p7 生效）；
- `skillsFor(act, ruleset, counterVersion?, character?, lexiconVersion?)` 第五参；
- `quizPoolFor(ruleset, voiceAvailable, forgeVersion?, lexiconVersion?)` 第四参；
- 切磋码版本束增列 `lexicon`（字段 `l`；旧码无此字段 = 旧池逐位同局，零破坏）；
- 仿真 `simulateAct({ lexiconVersion })` 透传；UI 开新战役注入 `lexiconVersion: 1`。
- **旧局零漂移**：不带 lexicon 的所有既有测试/基线快照数字逐位不变。

### 1.4 质量与诚实边界
- 粤拼人工编写（LSHK 粤拼方案），**待母语审校**（沿用 P7/P16 惯例，文档标注）；
- 题库为文字题（不依赖 TTS），听音题仍由 P13 辨音通道承担；
- 图鉴/练习场/SRS 自动收录（ALL_SKILLS 聚合，学习闭环零改动受益）。

## 2. 明确不做
- 不加新卡牌机制类型、不加新事件/道具/敌人（本期只做"内容量"）。
- 不动评分/声调引擎；不动 P16 平衡数值与换带阈值。
- 不做运行时 AI 或在线内容下载。

## 3. 验收门
- 契约：P17 内容完整性（粤拼逐句可解析、id 全局唯一、无空文案）、池门控
  （lexicon 缺省 = 既有池逐位不变）、题池合并、切磋码 `l` 字段往返恒等、存档往返。
- 仿真：`tests/sim/p17-balance.test.ts`——全版本开（含 lexicon）三幕落带、零超时、
  梯度仍在；基线（不带 lexicon）与 P16 快照**逐位一致**（零漂移证据）。
- 全门：biome / tsc / vitest / build / 预算 / E2E（内容计数更新）/ 视觉（标题屏基线重建）。

## 4. 实施记录（2026-09-22 完工）

### 交付量（实测）
- 战斗短句 **+220**（幕1 73 / 幕2 74 / 幕3 73）：全库 269 卡、**266 句可开口**（47 → 266）。
- 问答题 **+80**（词义 30 / 场景 25 / 拼音语音 25，全文字题不依赖 TTS）：题池 76 → **156**。
- 汉字覆盖 116 → **370**（口语高频字大头；指标口径修正见 §0）。
- 音节覆盖：粤拼带调音节 114 → **250+**（含三入声尾 -p/-t/-k 高频字）。

### 版本门控与零漂移
- `lexiconVersion?: 1` 全链路：CampaignConfig → state → skillsFor 第五参 / quizPoolFor 第四参 →
  切磋码版本束（字段 `l`，PAYLOAD_KEYS 白名单登记）→ simulate 透传 → UI 开新战役注入。
- **基线零漂移有直接证据**：`tests/sim/p17-balance.test.ts` 断言不带 lexicon 的贪心三幕
  wins = [191, 202, 215]，与 P16 报表逐位一致；p13/p15 快照测试不动即过。
- 顺手修复 P15 缺口：`challengeFromRun` 此前不带 `forge` 字段（锻造局发码 → 对方开的不是
  同一局，违背同码同局）；现 forge + lexicon 均随码携带。

### 平衡（仿真，种子基 539363609，确定性）
- 词海局（全版本 + lexicon）三角色三幕实测 66.7–81.3%，全部落 55–85% 变体带，零超时；
  技能梯度仍在（voiceMean 92 > 60）。
- 词海局胜率比不带 lexicon 的同配置高约 4–10 点：卡池扩大给贪心 Bot 更多优质选择，
  属"学习内容多 = 打得顺"的可接受方向；如需收窄，后续可按稀有度配额。

### 质量门
- 586 测试全绿（+10：契约 5 / 仿真门 5）；E2E 55/55（标题计数 49→269）；视觉基线重建后
  16/16（偶发首载抖动重跑即绿，P15 起已知，非本期引入）。
- 预算：本体 JS **132.8 / 350 KB gzip**（+18 KB 装 220 句 + 80 题，全部静态数据）。

### 待母语审校
P17 全部粤拼为 LSHK 方案人工编写（含入声/破读/语气词），沿用 P7 惯例待母语者过目；
审校后如有修正，只需改 `src/core/content/p17/` 数据文件（契约测试自动跟随）。

### 后续扩容建议（非本期）
按场景批注追加（如：家庭称谓/职业/身体/颜色各 20 句），每批走同一管线：数据 → 粤拼契约
（音节数=字数）→ 仿真带校验 → 视觉基线核对。
