# 声震龙楼 · v1 提审与上线包（微信小游戏）

> 面向分支 `feat/minigame`，产物目录 `minigame/dist`（`node minigame/build.mjs` 生成）。
> 个人主体 + IAA（流量主广告）路线，无内购、无账号系统、无服务器。
> 政策类内容整理于 2026-09，**以微信官方文档为准**。

## 1. v1 功能范围（提审版本说什么）

- 玩法：粤语街坊卡牌闯关（类杀戮尖塔牌组构筑）。听街坊一句粤语 → 从手牌选一句能「接住」对方意图的回应 → 按住录音开口跟读 → 读得准伤害加倍。
- 内容：4 章 × 18 张句子卡（茶餐厅 / 出行问路 / 唐楼邻里 / 写字楼搵工），16 位街坊、12 个事件、8 个语法遗物（嘅／冇／咗／紧／可／识）、粤英混排学习卡面。
- 学习模式：全语音示范（132 条预录粤语，无系统 TTS 依赖）、粤拼 + 普通话注释、章首词块拼句课、跨局生词温习地摊、间隔重复调度。
- 无：内购、排行榜、UGC、聊天、抽奖。未成年人相关：无诱导分享（仅开放普通分享菜单，无分享奖励）；录音仅本机实时评分，不上传、不存储。

## 2. 上线前流程（按顺序）

1. **微信认证**（个人主体 300 元/年，认证后才有流量主资格）。
2. **IAA 资质审核 + 小游戏备案**：账号设置 → 小游戏备案 → 去完善。需三份模板文档（自查自审报告、著作权声明、平台代办授权书）。平台初审 1–2 个工作日，主管部门 10–20 个工作日；名称、主体必须与备案一致，被驳回会重头排队。
3. **适龄提示**（必填）：本游戏无暴力、血腥、赌博、恋爱内容，全部玩法为语言学习与文字对话 → 建议标注 **「适合 12 周岁以上」**（内容教育向，低龄可玩但需家长引导识字；填 12+ 比 8+ 稳，避免评审以「幼儿不宜复杂操作」驳回）。
4. **隐私接口声明**（mp 后台 → 服务内容声明 → 用户隐私保护指引）：
   - 采集信息：**麦克风**（用途：跟读评分；处理方式：仅设备端实时分析，音频不上传不保存）；**本地缓存**（存档、学习记录，仅存于设备 wx.setStorage）。
   - 不申请通讯录、位置、相册、用户信息（getUserProfile 未调用）。
5. **类目**：一级固定「游戏」；二级选 **休闲游戏**（与卡牌闯关玩法相符；个人主体不可选文化互动/角色/牌类——卡牌二字不影响，描述里避免写「牌类」）。
6. **软著**（可选但强烈建议）：名称《声震龙楼粤语学习小游戏软件》，个人申请走版权局线上登记，约 1–2 个月；加急收费。有软著能显著降低备案著作权声明环节的驳回率。
7. 备案下号后再点**发布**。审核通常 1–7 个工作日；首次提交备注写「教育休闲类，无虚拟支付」。

## 3. 广告位（流量主）

- 开通门槛：累计独立访客 > 500（个人流量主以官方最新规则为准）。
- 已接三处（`minigame/src/config.ts` 填 adUnitId 即生效，留空 = 自动跳过 = 联调安全）：
  - 激励视频 `extraCard`：战斗失败后「看广告多一张牌」，每场一次。
  - 激励视频 `revive`：整局失败复活，每局一次。
  - 插屏 `interstitial`：回首页时展示；前 2 局不打扰、间隔 ≥3 分钟。**无 banner、无强制弹窗广告**。
- 合规红线（已规避）：不以奖励诱导分享；广告不阻断学习流程主路径；未成年人模式下微信自动限制广告个性化。

## 5. 人工试听

打开预览服务里的 `/audio-check.html`（132 条表格逐条听）。重点：每句开头不吞字、结尾不截半、无错读。**任何一条不对，删掉 `minigame/assets/audio/street/` 对应 mp3 重录再跑 `node minigame/build.mjs` 即可**，游戏对缺失音频自动降级为粤拼跟读提示，不会崩。
