# P8-C · 语音深化详细方案

> 2026-09-19 · 用户选择进入 P8-C；先制定本方案，再按「音节诊断 → SRS 声调画像 → 三处反馈界面」实施。
> 状态：**实现与本地验收完成**。本期未修改战斗数值、评分权重、端侧/在线适配器优先级，也未把浏览器评分包装成专业发音认证。

## 1. 目标

把现有“整句字准 / 调准分”推进为可执行的学习反馈：玩家知道**哪一个音节、目标是几调、当前轮廓更接近什么、下一遍应怎样调整**；长期报告按粤语六调累计本机画像，并把薄弱调与错词本复习关联。

交付范围：

1. 音节级声调诊断与一条明确的下一步建议。
2. 六调本机学习画像、短句最近一次字准/调准/薄弱音节记录。
3. 战斗判定、练习场、学习报告三处一致的反馈语言。
4. 旧 `voice-tower-srs-v1` 数据无损兼容；无 F0 通道时明确降级，不伪造调准结论。

## 2. 公平与科学边界

- `scoreToneContour` 的既有分数、DTW 距离、几何平均和战斗合成权重保持不变；只附加诊断元数据。
- “更接近某调”仅在另一调型斜率明显不同且距离显著更小时输出；水平调族及相近升调之间不武断判错调。
- 音节切分仍是短句等时近似，界面继续声明结果仅用于游戏学习反馈，不等同专业声学测评。
- Web Speech 没有本地 F0 通道时只给字准建议，六调画像不写入伪数据。
- QTE 和开发者手动判定不进入学习档案。
- 学习反馈不增加攻击、护甲、能量、掉落或隐藏奖励；允许玩家学习，但不改变黄金战斗契约。

## 3. 纯规则与数据结构

### C1 音节诊断

`core/tone.ts` 在保持原有 `score` / `perSyllable` 的同时，为每个音节返回保守的 `detectedTones`：

- 没有显著错调证据：等于目标调，不显示“错成某调”。
- 有显著不同轮廓：记录最接近调型，供可解释反馈使用。

新增纯函数模块 `core/voice-coach.ts`：

- 从粤拼拆出音节，与目标调、音节分、保守检测调对齐。
- 档位：`稳`（≥85）、`将稳`（65–84）、`重点练`（<65）。
- 选择最低分音节为本次焦点；同分按句中顺序，保证确定性。
- 建议优先级：字准明显偏低 → 先说清字；否则调准焦点 → 给目标调口诀；无 F0 → 说明通道限制；全部稳定 → 建议保持节奏再读一次。

### C2 SRS 六调画像

在既有 SRS 本地存储键上向前兼容扩展，不另起割裂档案：

- `SrsStats.toneMastery[1..6]`：每调累计 `attempts / sumScore / bestScore / lastScore`。
- `SrsEntry` 可选记录最近 `lastWordScore / lastToneScore / focusTone / focusSyllable`。
- `AttemptInput` 可选接收目标调序列与音节分；仅长度合法、分数有限、调号 1–6 时累计。
- 加载旧档时补齐六调空桶并清洗异常字段；旧条目保持可读。
- `dailyPicks` 仍以到期优先；未到期补位时，同等综合弱度下优先最近调准更弱的句子。
- 学习报告输出六调平均、采样数与当前最弱的**已采样**声调；未采样显示“待采样”，不当作 0 分。

## 4. 界面

### C3 战斗判定

真实端侧语音有音节数据时，在“发动技能”前显示：

- 最弱音节、目标调、该音节分数。
- 仅在有显著证据时显示“本次轮廓更接近 X 调”。
- 一条目标调口诀；可再次收听整句示范。

无 F0 时显示“本次仅依据字准”，不虚构音节诊断。QTE 保持现状。

### C4 练习场

- 每个声调胶囊显示该音节分数和文字档位，不只靠颜色。
- 焦点音节高亮并展示“下一遍只盯这一处”的建议。
- 曲线与原始三项分解继续保留；重复练习每次都进入 SRS。

### C5 学习报告与每日三句

- 新增六调画像网格：调名、均分、采样音节数；当前薄弱调显示为“今日重点”。
- 从错词本中优先列出与薄弱调关联的短句作为练习入口。
- 错词条目显示最近字准 / 调准及焦点调。
- 标题“每日三句”在有记录时显示焦点调徽标，记忆曲线含义不变。

## 7. 明确不做

- 不训练或下载新声学模型，不宣称识别出声母/韵母级错误。
- 不做录音回放或云端教师点评，不上传学习档案。
- 不按诊断结果改变战斗倍率，不增加“练习刷 buff”。
- 不做母语者语料审校结论；自动反馈仍需真人粤语试玩验证。

## 8. 实装与验收结果（2026-09-19）

### 已完成

- `ToneScoreDetail.detectedTones` 已落地：复用既有 DTW 六调比较，只在斜率族明显不同且距离优势超过既有错调门槛时报告其它调型；计分公式与分数完全不变。
- 新增 `core/voice-coach.ts`：粤拼音节对齐、三档文字状态、最低分焦点、字准优先与无 F0 诚实回退均为纯函数。
- SRS 原键向前兼容扩展：六调各自累计音节数 / 均分 / 最佳 / 最近分；错词保存最近字准、调准、焦点音节和目标调。旧档加载会补齐六个安全空桶。
- 战斗判定新增音节焦点、保守错调解释、目标调口诀和“再听整句”；QTE 不伪装成语音反馈。
- 练习场的每个调型胶囊显示分数与“稳 / 将稳 / 重点练”，最低音节以文字和边框双重标记。
- 学习报告新增六调画像、当前已采样薄弱调、关联错词快捷练习；标题“每日三句”和错词条目显示焦点调。
- 只持久化分数聚合；录音和 F0 帧未写入存储，未增加网络服务、运行时依赖或媒体素材。

### 体验路径与限制

1. 启用并准备好端侧 SenseVoice 模型；Web Speech 仍只有字准，不会伪造声调结论。
2. 真声施法后，在发动前查看“下一遍怎么练”；这段反馈不改变本次战斗分数。
3. 标题进入“练习场”反复跟读，音节胶囊和曲线会同步更新。
4. 返回标题进入“学习报告”，查看六调画像与“今日重点”关联短句。

音节边界仍采用短句等时近似；自动分数、最接近调型与 TTS 系统声都不能替代母语者审校。真人粤语发音、不同设备麦克风和长时间移动端体验仍待实测。
