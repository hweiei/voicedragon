# P8-D · 学习闭环详细方案

> 2026-09-19 · 用户选择继续 P8-D；先制定本方案，再按「本地日历聚合 → 趋势与目标 → 档案备份恢复」实施。
> 本期不新增云端账号、排行榜或遥测，不保存识别文本、录音、逐帧 F0，也不改变战斗评分与数值。

## 1. 目标

P8-C 已能回答“这一遍错在哪”，但仍缺少三个长期问题的答案：

1. 今天是否完成了可执行的开口目标？
2. 最近两周是在进步，还是只看见一个全期平均数？
3. 换浏览器或清理站点数据前，如何把学习档案带走并安全恢复？

P8-D 将现有 SRS 扩展为纯本地、可迁移的学习闭环：每日聚合、连续练习、14 日趋势、每日三句完成度，以及显式确认的 JSON 备份恢复。

## 2. 数据最小化与隐私边界

### D1 每日聚合，而非逐次录音日志

`SrsStore` 新增可选兼容字段 `history`，每个本地日期只保留一条：

- 日期键、尝试次数、综合分总和、字准总和、调准次数与总和。
- 当天练过的不同技能 ID；不记录识别文本、候选词、音频、F0 曲线或每次时间点。
- 最多保留最近 90 个有练习的日期，避免本地数据无界增长。

日期按用户本地日历计算，不把 UTC 跨日误当成新一天。QTE 与开发者键盘判定继续不进入学习档案。

### D2 可解释目标

- 每日目标固定为 **3 个不同短句**；同一句重复练习会增加尝试统计，但只完成一个目标格。
- 标题页显示“今日开口 x/3”和当前连续练习天数。
- 既有“每日三句”仍由 SRS 到期优先推送；目标进度按当天练过的不同短句计算，不因条目复习后改期而倒退。
- 没有错词时也可从练习场自由选句完成目标；不为了连续天数伪造分数或自动打卡。

### D3 趋势口径

学习报告新增最近 14 个自然日趋势：

- 每日综合均分、字准均分、调准均分（无 F0 则为空）、尝试数。
- 无练习日期明确显示空档，不用 0 分压低均值。
- 连续天数按“今天有练习则从今天回溯；今天未练则从昨天回溯”计算，允许用户当天尚未开始时看见此前连续记录。
- “较前期变化”仅在 14 日窗前后半段各至少有两个练习日时显示；否则写“数据不足”，不制造趋势结论。

## 3. 学习档案备份与恢复

### D4 版本化 JSON

新增 `core/learning-archive.ts` 纯函数：

- 导出包固定 `{ kind, version, exportedAt, store }`，当前 `version = 1`。
- 导出内容只有 SRS 条目、聚合统计、六调画像和日历聚合；不包含游戏存档、设置、识别文本、录音或 F0 帧。
- 导入严格检查标识、版本、对象形状和数值边界；复用 SRS 归一化，异常字段丢弃而不是进入运行态。
- 文件上限 1 MiB，防止误选大文件卡住页面。

### D5 恢复策略

- 本期定义为“备份 / 恢复”，采用**覆盖本机学习档案**，不做伪安全的统计相加。
- 原因：现有存储是聚合统计，没有逐次唯一 ID；盲目合并同一备份会重复累计。
- 选中文件后先展示导出时间、开口次数、短句数、错词数和有记录天数；用户二次确认才覆盖。
- 取消、非法文件、未知版本或超限文件均零副作用；成功后立即重绘报告。

## 4. 模块与实施顺序

1. `core/srs.ts`：日历聚合、90 日裁剪、每日目标、连续天数与 14 日趋势纯函数。
2. `adapters/storage.ts`：旧档加载补 `history: []`；继续沿用 `voice-tower-srs-v1`，不破坏已有设备数据。
3. `core/learning-archive.ts`：版本化导出、严格解析与归一化；单元测试先行。
4. `ui/ui.ts`：标题目标条、学习报告趋势、导入/导出和确认流程。
5. CSS / E2E / 文档 / codegraph / 全质量门。

## 5. 验收门

- 原 347 项测试、29 项 E2E 不放宽；P8-B 平衡仿真结果保持。
- 单测覆盖：同日聚合、不同短句去重、本地日期、90 日裁剪、连续天数、空档趋势、趋势变化门槛、导出往返、非法/未知版本拒绝、旧档补历史。
- E2E 覆盖：标题目标进度；报告 14 日趋势；JSON 下载；导入预览、取消零副作用、确认覆盖；390px 无横向溢出。
- `npm run ci`、全部 Playwright、`npm run sim:p8b` 全绿。
- 首包游戏本体 JS ≤350 KB gzip；零新增运行时依赖和素材。

## 6. 明确不做

- 不做账号、云同步、跨设备自动合并或在线排行榜。
- 不保存逐次发音明细、识别文本、录音和 F0 帧。
- 不用连续天数提供战斗 buff，不用焦虑文案惩罚断签。
- 不宣称两周聚合可以替代教师评估或母语者反馈。
