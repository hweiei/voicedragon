## 4. 诚实边界

- 码只约定**身份**（幕/种子/版本束/角色/词缀/难度），不携带牌组、路线与操作；「同码同局」指开局一致 + 同操作同结果，不保证双方同分。
- 战绩簿是**本机**记录，没有排行榜与云端校验：胜负凭码自证（分享行含码哈希，对方可复跑复盘）。
- 切磋码可直达未解锁的幕（对方邀请即入场）；但**不写解锁状态**——战役元存档的 `bossCleared` 只在本机真正击破该幕 Boss 时点亮。
- E2E 中「发起切磋」前把局势推到结算相走的是调试口 `engine.emit`（真实流程需打完整局），与 P11 彩累积走调试 API 同策略。
- 剪贴板 API 在桌面/移动浏览器均可用，但沙箱预览或权限被拒时只提示手动复制，不伪造成功。
- 本沙箱（单核 headless、无 GPU）里 QTE/演出类 E2E 有时序抖动：同一用例在基线树（`git worktree` @ HEAD）
  也偶发失败，且与并行任务争用预览端口（4173）相关；串行重跑 46/46 稳定通过，判定为环境抖动而非本期回归。
- 幕间续行会摘掉码身份（码只约定它写明的那一幕）：续行之后的塔属于玩家自己，不再计入该码战绩簿。
