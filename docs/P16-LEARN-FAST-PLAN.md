# P16 乐学快打 · 学习体验优化（学习效率 × 节奏 × 反馈）

> 2026-09-22 · 立项动因（玩家/仓库 Owner 实测反馈）：
> 「学习粤语效率很低：小怪血量太高、词汇少、闯关没有粤语句子、交互不好、特效少、游玩反馈不高」。
> 本期是**玩家体验向调优**，不新增系统、不新增素材、不碰零后端红线。

## 0. 现状数据（立项时实测）

| 维度 | 数值 | 问题 |
|---|---|---|
| 全库粤语短句 | **43 句**（含绝技/反击） | 对语言学习游戏偏少 |
| 问答节点 | 每张图 2–3 个，题库仅 **8 题** | 闯关中文化输入密度低，题很快重复 |
| 小怪血量 | 基础 34–48，曲线 +7.5%/等效层 | 低分档（入门 0.78×/未稳 0.52×）打得慢 |
| 档位倍率 | 正音 1.32 / 清晰 1.0 / 入门 0.78 / 未稳 0.52 | 初学者（低分档占大头）惩罚过重 → 每句练习周期被拉长 |
| 判定反馈 | 伤害浮字/抖动/白闪/彩已有 | **施法档位（正音/清晰…）无独立弹出**，学习回报感弱 |

## 1. 批次与验收

### F1 节奏提速（小怪血量太高 → 学习效率低）
- 档位倍率：入门 0.78→**0.92**、未稳 0.52→**0.72**（正音/清晰不变，保住"说好才有高光"的落差）。
- 基础小怪血量 **−20%**、精英 **−10%**、Boss 不动（Boss 击杀保持仪式感）。
- **平衡门变更（Owner 指令）**：贪心参考 Bot 胜率带由 45–65% 调整为 **55–75%**——
  本作是学习工具，"赢得顺、说得多"优先于挑战压力；`tests/sim/balance.test.ts` 阈值同步更新，
  随机 Bot 下限照旧。旧带数据存档于 `docs/BALANCE-REPORT.md` 历史。

### F2 学习密度（词汇少 / 闯关没有粤语句子）
- 问答节点：每图 2–3 → **3–4**；问答校验下限同步（`问答不足 3 个`）。
- 题库：8 → **16** 题（新增粤语用语/语音知识题，沿用既有题型，诚实降级规则不变）。
- 新战斗短句 **+6**（每幕 2 句，入 `EXPANSION_SKILLS`，不动基础表——AGENTS 红线）：
  一幕「早晨 / 多謝」、二幕「幾錢 / 食飽未」、三幕「一言為定 / 好嘢」。
  粤拼人工编写，沿用 P7 惯例标注**待母语审校**。

### F3 判定反馈（游玩反馈不高）
- 施法结算在既有伤害浮字之外**追加档位浮字**：正音！/清晰/入门/未稳（纯函数计划层，
  与伤害共用对象池与预算；reduce-motion 走 calm 降级）。

## 2. 明确不做
- 不新增敌人机制/词缀；不改敌人攻击曲线（只调血量，少挨打而非少打人）。
- 不动评分/声调引擎；不动 P13 保底与力量化；不新增素材与运行时依赖。
- 不做新角色、不做第四幕（留给下一期评估）。

## 3. 验收门
- `npm run sim`：贪心三幕胜率落 55–75%，随机 Bot 仍接近下限，零超时；场均回合下降。
- 契约：内容完整性（新句粤拼可解析、入池正确）、问答节点下限、旧局零漂移（旧局无 P16 内容）。
- 视觉/单测：`fx-plans` 档位浮字计划确定性；全量门 `npm run ci` 绿。

## 4. 实施记录（2026-09-22 完工）

### 数值定案（全部经仿真校准，勿按直觉回退）
- 档位倍率：入门 0.78→**0.88**、未稳 0.52→**0.62**（正音 1.32 / 清晰 1.0 不变）。
  0.92/0.72 首版曾致变体局（锻造开局）冲到 81–82%，收紧一档后全门归带。
- 敌人血量：幕1–2 小怪 −20%、幕3 小怪 −10%（终幕保留强度）、各幕精英 −10%、三 Boss 不动。
  幕3 曾按 −20% 一刀切，胜率 77% 越带，回 −10% 后 72% 归带。
- 凤冠花旦「水袖回风」叠甲 12→**2**：叠甲×沉默构成磨甲死锁（仿真定位：敌方 130 甲、
  我方弱牌组 60 回合零进度），真实玩家同样受困——这是 P16 顺带挖出的既有设计陷阱。
- 仿真单场安全阀 60→90 回合：真实游戏无回合上限，旧阀把"弱牌组正当长线战斗"
  （诊断实例：敌方剩 9 血 0 甲、差一回合获胜）误判为死锁；新阀只抓真死锁。
- 平衡门换带：基线三幕 55–75%（实测 63.7 / 67.3 / 71.7），变体门 55–85%
  （锻造/词林满配等叠加增益本就高于基线）；`BASELINE_WINS` 快照按 P16 回填。

### 结果（对立项数据）
- 场均回合：2.3–2.8 → **1.9–2.4**（每句练习的战斗周期缩短约两成）。
- 题库 8→16，问答节点每图 2–3 → **3–4**：单局文化输入密度约翻倍。
- 战斗短句 43→**49**（每幕 +2，入 `EXPANSION_SKILLS`，基础表只读红线不动）。
- 档位浮字（正音！/清晰/入门/未稳）接入 hit/skill 演出计划（纯函数 `tierFloaterFor`）。

### 验收门
- `npm run sim`：三幕贪心 63.7/67.3/71.7，零超时；随机下限 1.0/2.7/6.7（技能梯度仍在）。
- 572 单测/契约/仿真/属性全绿；55 E2E、16 视觉回归（战斗屏基线按新血量重建，二轮自比稳定）。
- `npm run ci` 全门通过。
