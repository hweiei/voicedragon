# v0.3.0 · 完整首章测试版交付

## 可交付范围
第一章从开局到通关、复习、备份、离线与静态部署全部连通。它不是已经教完全部粤语的课程，也不冒充专业发音评测器。

### 用户流程
1. 第一层学习问候，听内置示范、录音回听或明确选择阅读模式。
2. 领取不重复锦囊，选择教学巷/实战街，循序学习请求、点单、问价、感谢。
3. 终层按顺序完成三轮：招呼店员 → 完整点单 → 感谢送饮品的服务。中途可刷新继续。
4. 三轮都录音才计为完整对话的录音完成；混合阅读照常通关但不伪记整段口语完成。
5. 结算、重开、每日回忆、手账JSON导出和确认恢复。手账与原版存档独立。
6. 原版完整冒险通过 `?mode=classic` 保留，旧挑战链接兼容。

## 本轮关键补齐
- 用户试听选声后生成并内置 10 段粤语合成音频；六句课程、三个分句、一句店员回应。
- 正常/慢速播放保留音高，无需系统粤语音色；加载失败明确提示，不用普通话替代。
- 音频纳入 Service Worker 离线预缓存；构建产物检查验证文件和缓存清单，浏览器验证实际解码与播放。
- 音频来源、大小、SHA-256 清单见 `public/audio/yue/provenance.json`。
- 三轮终层有持久化轮次和录音完成标志，旧通关存档不会被强迫重做新增对话。
- 备份限制 1 MiB、白名单恢复、版本校验、预览句数后二次确认；取消/非法文件不覆盖数据。
- 生产产物不附源映射；发布ZIP只包含静态部署文件，不包含私钥、Git历史或环境凭据。

### 本轮发现并处理的历史验收问题
- P8-B独立报表脚本还用P8期45–65%阈值，与已存在的P16/P17契约55–85%冲突。本轮只对齐脚本与现有契约，未改游戏数值或放宽当前测试。
- 老战斗截图继承地图滚动位置导致偶发裁切偏移。改为等待toast结束、固定页面顶部、fullPage截取；四张战斗基线按新的截取规范重建并查看，未更新其他基线或放宽像素容差。
- 首轮发布串行检查中旧切磋测试在语音适配器初次异步重绘前点击，直接改引擎相位会得到未实际开局的伪结算。夹具改为等待适配器就绪和真实开局标志，专项重复15/15通过，再完整重跑发布链通过。

## 部署与权限
- 工作流 `pages` 在main的 `ci` 成功后部署相同提交SHA，或管理员手动触发；不是任意分支一推就上线。
- 首次必须由仓库管理员在 Settings → Pages → Source 选 GitHub Actions；私有仓库Pages能力还受账户方案限制。
- SSH deploy key 可以推送Git，但不能替代GitHub API/仓库管理员权限。
- 本次公开GitHub API查询返回404，目标Pages网址也返回404。因此是否公网部署成功必须以实际响应确认，不能把代码推送成功冒称上线成功。
- 不需上述权限也能使用当前实时预览，或将静态ZIP上传至Cloudflare Pages等静态托管。
