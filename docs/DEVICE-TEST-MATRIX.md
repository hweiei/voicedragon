# P8-E · 设备与线上发布验收矩阵

> 自动化只能证明浏览器引擎与构建契约；WebKit 模拟器不等于 iPhone，localhost 不等于 CDN。未填入真实设备、系统版本、部署 URL 和日期的项目一律视为**待验收**。

WebKit 项的离线跳过原因：Playwright WebKit 在 `context.setOffline(true)` 后会绕过已控制页面的 Service Worker，并对 `reload/fetch` 抛内部 `Load failed`；这不是产品通过或失败的证据，因此不伪造成绿色结果。

## 2. iPhone / iPad Safari 真机（待验收）

- [ ] 首次联网打开，无白屏、脚本错误或横向滚动。
- [ ] 分享 → 添加到主屏幕；图标、名称、启动画面和竖屏方向正确。
- [ ] standalone 模式顶部刘海、底部 Home Indicator 安全区不遮挡按钮。
- [ ] 成功打开一次后断网冷启动；标题、设置、练习场和无声破阵拍可用。
- [ ] 麦克风首次授权、拒绝、系统设置重新授权三条路径均有可理解反馈。
- [ ] 系统存在粤语语音时“听一听”可播；不存在时不阻塞游戏。
- [ ] 文件 App 可导入学习档案；导出 JSON 可保存/分享，中文 UI 不乱码。
- [ ] 320–430px 宽、横竖屏切换与软键盘弹出后无关键按钮丢失。
- [ ] 低电量模式 / 减弱动态效果下信息完整、无持续高负载。
- [ ] P14 自动收音（端侧引擎）：说 1 秒短语 → 停顿，判定在体感 ~0.3 秒内到达；连说 5 句不串句、不误截断。
- [ ] P14 真机端到端时延记录：说话结束 → 结果上屏的秒表读数（iOS/Android 各 3 次，填在这里；策略级数字见 docs/P14-LATENCY-REPORT.md）。

## 3. Android Chrome 真机（待验收）

- [ ] 安装提示或浏览器菜单“安装应用”可用，standalone 启动正确。
- [ ] 首次打开、后台切回、系统回收后重开均能恢复本地存档。
- [ ] 断网冷启动可进入标题并完成无声破阵拍战斗。
- [ ] 麦克风授权 / 拒绝 / 仅本次授权均正确降级。
- [ ] 端侧模型下载显示进度；切后台或断网后重新进入可从已有分片续传。
- [ ] 下载完成后飞行模式可运行端侧识别；不得发出音频网络请求。
- [ ] 存储空间不足或浏览器清站点数据时给出可理解错误，不破坏游戏存档。
- [ ] 学习档案导出、系统文件选择器导入与二次确认可用。

## 4. 桌面与辅助技术（待验收）

- [ ] macOS Safari：标题、设置、WebKit 离线、麦克风、系统粤语 TTS。
- [ ] Windows Edge：安装、麦克风、Web Speech / QTE 降级、文件下载。

## 5. 线上域名与网络（部署后待验收）

- [ ] `curl -I` 确认 CSP、HSTS、Permissions-Policy、缓存头真实生效。
- [ ] `index.html` / `sw.js` / manifest 为 no-cache；哈希资源为 immutable。
- [ ] 线上移动与桌面 Lighthouse 均满足仓库预算，并记录 URL、时间和报告版本。
- [ ] 主流聊天工具抓取 og/twitter 标题、描述与 1200×630 分享图。
- [ ] 慢速网络首次打开仍先呈现可玩的 QTE 壳；PWA 安装不要求 230MB 模型。
- [ ] 230MB 模型的 Range 请求、CORS、断点续传和 CDN 可用性在真实移动网络验证。
- [ ] 发版后旧 Service Worker 客户端能更新到新版本，进行中的局不被强制刷新。
